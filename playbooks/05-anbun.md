# 05 按分

```
python3 scripts/anbun.py out/an.jsonl --out out/anbun.jsonl
```

- `config/anbun.json` に決まりがある店だけ分けます。**決まりが無いものを勝手に分けません**
- 割合（例：仕事で使う時間・面積の割合）と理由を決まりに書きます。割合の決め方は税理士に確かめてください
- 1円未満は `kiri` の決まりで寄せます。分けた合計は元の金額と1円まで同じになります
- 「私用」の分は会計ソフトに出しません。個人事業なら事業主貸、法人なら役員への貸付など、どう記帳するかは税理士に確かめます
- 2つの事業（部門）に分けたいときも同じ形で書けます（例 `{"事業A": 0.5, "事業B": 0.5}`）。会計ソフトの「部門」に入れるかは、使い方に合わせてオーナーと決めます
