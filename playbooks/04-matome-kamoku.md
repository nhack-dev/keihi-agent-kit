# 04 まとめる・科目の案を出す

```
python3 scripts/chofuku.py out/meisai_*.jsonl out/ryoushuu.jsonl --out out/matome.jsonl
python3 scripts/kamoku_an.py out/matome.jsonl --out out/an.jsonl
```

## chofuku.py がすること

- 領収書と明細の同じ買い物を1件にする（金額が同じ・日付のずれが3日以内・店の名前が似ている）。1本の明細には領収書1枚だけ
- 同じ日・同じ店・同じ額が複数ある → **消さない**。本当に2回買ったことがあるので、要確認で並べる
- つながらなかった領収書 → 現金払い・別のカード・明細がまだ、のどれか。要確認

## kamoku_an.py がすること

| 確からしさ | どこから | 扱い |
|---|---|---|
| 高 | オーナーの決まり（kamoku_kimari.json） | そのまま案にする |
| 低 | 店の名前からの一般的な案（kamoku_ippan.json） | 必ずオーナーが見る |
| なし | どれにも当たらない | 何を買ったかを聞く |

いつも要確認にするもの：10万円以上（資産の扱い）・飲食（会議か接待か）・私用と混ざりやすいもの・マイナス・登録番号が怪しい・税区分が分からない

**すべて案です。** 決めるのはオーナーか税理士です。

## 要確認の聞き方

1. `templates/kakunin-hyou.md` の型で、上から3件ずつオーナーへ
2. 答えをもらったら記録に書き、同じ店がまた来そうなら `kamoku_kimari.json` に足す案を出す
3. 税の判断が要るものは `templates/zeirishi-memo.md` へ
