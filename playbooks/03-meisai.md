# 03 カード・銀行の明細を読む

1. カード会社・銀行の画面から CSV を落とし、`data/meisai/` に置く（落とすのはオーナー。ログインは自動にしない）
2. 読み込む（カード・口座ごとに `--kouza` の名前を付ける。`config/kaikei.json` の kouza と同じ名前）

   ```
   python3 scripts/meisai_yomu.py data/meisai/カードA_2026-09.csv --kouza カードA --out out/meisai_cardA.jsonl
   python3 scripts/meisai_yomu.py data/meisai/銀行_2026-09.csv --kouza 普通預金 --source bank --out out/meisai_bank.jsonl
   ```

3. 表示の「合計」を、CSV の合計・カード会社の請求額と比べる。合わなければ先へ進まない
4. 「読めない行」があれば CSV を開いて確かめる（推測で埋めない）

## 気をつけること

- 銀行の明細には、カードの引き落とし（まとめて1行）が入る。カードの明細を別に読んでいるなら、**引き落としの行は経費にしない**（二重になる）。科目の案は出るので、オーナーに「カードの引き落とし」と答えてもらい、決まり（jigyou_igai か専用の行）にする
- マイナスの行（返品・取り消し）は、元の取引を探して一緒に直す
- 同じ CSV を2回読んでも、同じ行は同じ印になるので増えません
