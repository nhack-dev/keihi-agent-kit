# 02 領収書を読む

文字の読み取りは、**あなた（エージェント）が自分で画像を見て**行います。外の読み取りサービスへ画像を送りません。

1. `data/ryoushuu/` の新しい画像・PDF を1枚ずつ開く
2. `templates/ryoushuu-kiroku.md` の型で1行書き、`data/ryoushuu.jsonl` に足す（読み直しの手順を必ず守る）
3. 確かめる

   ```
   python3 scripts/ryoushuu_kensa.py data/ryoushuu.jsonl --out out/ryoushuu.jsonl
   ```

4. 要確認が出たら、もう一度画像を見る。それでも読めなければ空のままオーナーに聞く

## 気をつけること

- 同じ領収書を2回書かない（ファイル名で確かめる）
- 1枚に2つの店のレシートが写っていたら、2行に分ける
- クレジットカードの「ご利用控え」と、お店の領収書の両方があるときは、同じ買い物です（chofuku.py が1件にまとめる）
- 個人の名前（同席者など）は、オーナーが書いてよいと言った範囲だけ
