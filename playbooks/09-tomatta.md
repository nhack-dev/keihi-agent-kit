# 09 止まったとき

| 出た表示 | よくある原因 | やること |
|---|---|---|
| 日付と金額の列が見つかりません | CSV の列名が候補に無い | 表示された1〜3行目の列名を `config/csv_katachi.json` に足す |
| 文字コードが UTF-8 でも Shift_JIS でもありません | 珍しい文字コード | CSV を落とし直す（形式を選べるなら UTF-8 か Shift_JIS） |
| 読めない行 N 件 | 日付・金額の形が違う | CSV を開いて確かめる。推測で埋めない |
| JSON として読めません | 記録の1行が壊れている | その行を書き直す（行番号が出る） |
| 『例』のままです | config/kaikei.json を合わせていない | 01-junbi.md の 3 |
| 取り込みで失敗した（会計ソフト側） | 科目・税区分・口座の名前の違い／列名の違い | 会計ソフトのエラーの行を見て、名前を一覧と比べる。`--sample` で列名をそろえる |
| freee：HTTP 401 | トークンの期限切れ・取り消し | オーナーに知らせる（refresh token の取り直しはオーナー） |
| freee：freee_plan_limit | そのプランで使えない API | CSV の取り込みに切り替える |
| freee：HTTP 429 | 呼びすぎ | 時間をおく。件数を絞る |
| 合計が明細と合わない | 読み込み漏れ・合計の行・重複 | 先へ進まない。読めない行・外した行を見る |

## 決まり

- お金・会計ソフト・税に関わることは、手を止めてオーナーに知らせる
- 直したら、同じ道具をもう一度動かして結果を確かめる
- 同じ止まり方が2回あったら、この表に1行足す案を出す
