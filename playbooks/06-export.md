# 06 会計ソフトへ取り込む CSV を作る

```
python3 scripts/export_freee.py out/anbun.jsonl --out out/freee_import.csv
python3 scripts/export_mf.py out/anbun.jsonl --out out/mf_import.csv
```

- **要確認が残っている行は出しません**（`--kakunin-mo` で出せるが、タグ・メモタグに「要確認」が付く）
- 事業以外・私用の按分・マイナスの行も出しません
- 作ったら、**オーナーが中身を見てから**取り込みます。エージェントは取り込みの画面を自動で操作しません

## freee会計（取引のインポート）

- 列の並び・決まりは公式ヘルプ「取引・口座振替のインポート（一括登録）」に合わせています（`scripts/export_freee.py` の先頭）
- できれば freee の画面から**サンプルのファイルを落とし**、`--sample サンプル.csv` で列名をそろえる
- 文字化けしたら `--sjis`
- 取り込むと全部新しい取引になります。**同じファイルを2回取り込まない**（二重になる）
- 最初は1〜2件だけのファイルで試し、画面で科目・税区分・口座を確かめてから全部を入れる

## マネーフォワード クラウド会計（仕訳帳のインポート）

- 列は公式ヘルプ「仕訳帳のインポート」の A〜AA 列に合わせています
- 借方＝科目の案、貸方＝支払った口座（カードなら未払金と補助科目など。`config/kaikei.json` の kouza）
- 「借方インボイス」の列は**空欄だと適格とみなされます**。登録番号の無い仕入れの値は `mf_invoice.nai` に決めて入れる
- 取り込むたびに新しい仕訳になる（2回入れると二重）
- 公式は「指定のサンプルフォーマットを使う・1行目を編集しない」としています。取り込みで止まったら画面のサンプルと列名を比べる
