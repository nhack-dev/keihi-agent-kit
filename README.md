# 経費精算 AI エージェント キット

あなたの AI エージェント（Claude Code など）にこのフォルダを読ませると、領収書とカード明細の整理を手順どおりに続けられるようにするための、手順書と小さな道具のセットです。

- 領収書の画像・PDF を、エージェントが自分で読んで記録にする（日付・金額・店・登録番号）
- カード・銀行の明細 CSV を読み込んで、同じ形にそろえる
- 1件ずつ「勘定科目」「税区分」の**案**を出す
- 按分（事業と私用、または2つの事業）の割合で分ける
- 二重に計上しそうなもの（領収書とカード明細の同じ買い物など）を見つける
- freee会計・マネーフォワード クラウド会計に取り込める CSV を作る（freee は API で直接登録もできる）
- 電子帳簿保存法の検索に使える一覧（取引年月日・金額・取引先）を作る

**税金の判断はすべて「案」です。** 科目・税区分・按分の割合・経費にしてよいかは、最後にあなたか税理士が決めます。

## 費用について

このキットそのものに費用はかかりません。動かすときにかかるのは、あなたが自分で契約するものだけです。

- あなたの AI エージェントの利用料（領収書の画像を読むのは、あなたのエージェントの画像読み取りです）
- 会計ソフトの利用料（freee の API は有料プランの事業所でだけ使える機能があります）

こちらのサーバー・鍵・文字読み取りのサービスは一切使いません。領収書や明細は、あなたのパソコンの中だけで扱います。

## 最初の10分

1. Python 3.11 以上が入っているか確かめます。

   ```
   python3 --version
   ```

2. 道具が動くか、見本のデータで確かめます（ネットにつながりません・鍵も要りません）。

   ```
   bash scripts/selftest.sh
   ```

   最後に「落ちた道具 0本」と出れば準備できています。

3. 見本で1周やってみます。

   ```
   python3 scripts/meisai_yomu.py samples/card_meisai.csv --kouza 見本カード --out out/meisai.jsonl
   python3 scripts/ryoushuu_kensa.py samples/ryoushuu.jsonl --out out/ryoushuu.jsonl
   python3 scripts/chofuku.py out/meisai.jsonl out/ryoushuu.jsonl --out out/matome.jsonl
   python3 scripts/kamoku_an.py out/matome.jsonl --out out/an.jsonl
   python3 scripts/anbun.py out/an.jsonl --out out/anbun.jsonl
   python3 scripts/export_freee.py out/anbun.jsonl --out out/freee_import.csv
   python3 scripts/export_mf.py out/anbun.jsonl --out out/mf_import.csv
   ```

4. AI エージェントに「AGENT.md を読んで、今月の経費をまとめて」と頼みます。Claude Code なら、このフォルダで起動するだけで `CLAUDE.md` から `AGENT.md` を読みます。

5. 本番で使うときは、`config/` の `*.example.json` を写して `.example` を外し、自分の会計ソフトの科目名・税区分の名前・カードの口座名に直します（`playbooks/01-junbi.md`）。

## 必要なキー

| もの | 何に使うか | 要るか |
|---|---|---|
| なし | CSV を作って、会計ソフトの画面から取り込む | これだけで使えます |
| freee のアプリ（OAuth） | freee へ API で取引・証憑ファイルを直接登録する | 任意。freee の開発者向けページでアプリを作り、あなたの事業所で許可します |

freee の手順は `playbooks/07-freee-api.md` にあります。

## できないこと（正直に）

- **税の判断はしません。** 案と、その理由と、確かめるべき点を出すだけです
- **領収書の文字読み取りは、あなたの AI エージェントが画像を見て行います。** 読み違いはあり得ます。金額・日付・登録番号は、エージェントが読み直しの手順（`playbooks/02-ryoushuu.md`）で確かめ、怪しいものは「要確認」に回します
- **マネーフォワード クラウド会計の公開 API は、このキットを作った時点では公式で確認できませんでした。** そのため CSV の取り込み（仕訳帳のインポート）だけに対応しています
- **カード会社・銀行の CSV の形は会社ごとに違います。** よくある列名は自動で見分けますが、合わない場合は `config/csv_katachi.json` に列名を足します
- freee の「取引のインポート」の文字コードは、公式ヘルプに書かれていません。取り込みで文字化けしたら `--sjis` を付けて作り直してください
- 電子帳簿保存法・インボイス制度の要件を満たすかどうかの最終判断は、税理士か国税庁の案内で確かめてください

## フォルダの中身

```
AGENT.md        エージェントへの指示書（役割・毎日やること・判断の基準・禁止・止まったとき）
CLAUDE.md       Claude Code 向け（AGENT.md を読むように1行）
playbooks/      作業ごとの手順
scripts/        小さな道具（Python 標準ライブラリだけ・既定は試し運転）
templates/      領収書の記録の型・税理士への確認メモの型・月の報告の型
samples/        架空の見本データ
config/         設定の見本
```

本物の領収書・明細・作った CSV は `data/` と `out/` に置きます（リポジトリには入りません）。

## このキットは N-Hack のAIエージェント専用です

このキットは N-Hack の受講生さん専用のプレゼントです。**N-Hack のAIエージェント
（N-Hack のプラグインを入れた Claude Code など）が、このパソコンで動いていること**を
前提にしています。

- どのスクリプトも、最初に `scripts/nhack_gate.py`（門）を通ります。門は、このパソコンに
  N-Hack のAIエージェントの「印」があるかを**読むだけ**で確かめます（ネットにつなぎません・
  何も書き換えません・プラグインには一切触れません）。
- 印が足りない環境では、スクリプトは動かずに止まります（終了コード 2）。この環境でだけ
  動くのが正しい姿です。
- いま N-Hack 環境かどうかは、次のコマンドで確かめられます。

```bash
python3 scripts/nhack_gate.py
```

N-Hack 以外のパソコンにコピーしても動きません。受講生ページ・コンサルチャンネルの案内に
沿ってご利用ください。
